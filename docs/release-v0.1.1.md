# CasioVideo 0.1.1

Primera release pública del reproductor y su formato CVID v1.

- Reproductor probado en una fx-CG50 física con el vídeo de colores incluido.
- Biblioteca con tres carátulas por fila, miniaturas y duración.
- Reproducción, pausa, saltos de 5 s, tema claro/oscuro y velocidad 0.5×–2×.
- Salida con EXIT y nueva apertura corregidas mediante el reinicio del punto de entrada de gint.
- Iconos de menú distintos para el estado normal y seleccionado.
- Intro CasioVideo con `samilososami.com`.

Copia **CasioVideo.g3a** y, si quieres probarlo inmediatamente, **COLORES.cvid** a la raíz de la calculadora. Expulsa la unidad antes de desconectarla.

El ZIP incluye esos mismos archivos, el manifiesto y SHA256SUMS. La web puede instalar el mismo binario desde esta release. Los MP4 originales necesitan conversión: el add-in reproduce CVID, no MP4.

Compatibilidad confirmada solo en fx-CG50. Otros modelos compatibles con `.g3a` podrían requerir adaptaciones; si cambia la resolución, la interfaz puede verse cortada o desajustada. No se garantiza compatibilidad con cualquier Casio.
